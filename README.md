# Stella — бот символического самопознания

Готовый стартовый проект Telegram-бота на Python. Интерфейс на русском языке, меню, расчёт нумерологического числа жизненного пути, карта дня с вопросом для самоанализа, комплексный отчёт-заготовка, обработка ошибок и тесты.

**Честное ограничение:** это рабочий MVP, а не законченная научная или профессионально валидированная методика. Астрологические вычисления пока не подключены: бот прямо сообщает об этом и не выдумывает положения планет. Таро используется как рефлексивная практика, а не гарантированное предсказание.

## Возможности
- `/start` — приветствие и меню
- `/help` — инструкция
- Нумерология: расчёт числа жизненного пути по дате рождения
- Таро: случайная карта из небольшого встроенного набора с вопросом для размышления
- Комплексный отчёт: нумерологическая тема + рефлексивный вопрос
- Команды не требуют сохранения профиля пользователя
- Секретный токен берётся из переменной окружения
- Тесты основных расчётов

## Быстрый запуск для новичка

### Шаг 1. Создай Telegram-бота
1. Открой Telegram и найди `@BotFather`.
2. Отправь `/newbot`.
3. Задай имя и username.
4. Скопируй токен. **Не публикуй его и не отправляй в чат.**

### Шаг 2. Установи Python
Установи Python 3.11 или новее с официального сайта https://www.python.org/downloads/

### Шаг 3. Установи зависимости
Открой терминал в папке проекта и выполни:

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

Затем:
```bash
python -m pip install -r requirements.txt
```

### Шаг 4. Добавь токен
Скопируй `.env.example` в файл `.env` и вставь токен после `TELEGRAM_BOT_TOKEN=`.

Пример:
```env
TELEGRAM_BOT_TOKEN=123456:replace_this_with_your_real_token
```

Не добавляй `.env` в GitHub — он исключён через `.gitignore`.

### Шаг 5. Запусти
```bash
python main.py
```
Открой своего бота в Telegram и нажми Start.

### Шаг 6. Проверь тесты
```bash
python -m unittest discover -s tests -v
```

## Как загрузить на GitHub
1. Создай новый репозиторий на https://github.com/new
2. Для первого запуска выбери **Private**, если пока не хочешь публиковать код.
3. Загрузи файлы этой папки через кнопку **Add file → Upload files** либо используй Git.
4. Проверь, что `.env` не загружен.
5. GitHub хранит код; чтобы бот работал 24/7, его нужно развернуть на хостинге.

Официальная инструкция: https://docs.github.com/en/repositories/creating-and-managing-repositories/quickstart-for-repositories

## Запуск 24/7
Для новичка можно использовать хостинг, поддерживающий Python worker и переменные окружения. Создай сервис из репозитория, задай переменную `TELEGRAM_BOT_TOKEN`, команда запуска: `python main.py`. Условия и бесплатные лимиты хостинга могут меняться; проверь их перед публикацией.

Не запускай один и тот же токен одновременно в нескольких экземплярах бота: это может конфликтовать при polling.

## Структура
- `main.py` — запуск Telegram-бота и обработчики
- `app/numerology.py` — числовой расчёт
- `app/tarot.py` — рефлексивные карты
- `app/report.py` — сборка комплексного отчёта
- `app/astrology.py` — честная заглушка до подключения эфемерид
- `data/meanings.json` — редактируемый словарь символических трактовок
- `tests/` — тесты

## Следующие профессиональные этапы
1. Подключить расчёт натальной карты через эфемериды и корректную обработку часовых поясов.
2. Сделать анкету рождения: дата, время, населённый пункт, точность времени и согласие на обработку.
3. Добавить отдельные модули совместимости, архетипов и матрицы судьбы с описанием конкретных традиций.
4. Создать версионируемую авторскую методику: источник трактовки, правила синтеза, ограничения, примеры.
5. Добавить базу данных только если нужно сохранять профили; дать пользователю способ удалить данные.
6. Добавить логирование без токенов и чувствительных данных, обработку ошибок и мониторинг.

## Принципы
- Символические трактовки не являются доказанным способом предсказания судьбы.
- Не выдавать советы бота за медицинские, юридические или финансовые рекомендации.
- Не обещать точность совместимости или гарантированное будущее.
- Не собирать и не хранить данные без понятной причины и согласия.
